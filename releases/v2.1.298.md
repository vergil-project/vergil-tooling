
# Release 2.1.298 (2026-11-10)

## Bug fixes

- **make the packaged cppcheck suppressions file comment-free for cppcheck 2.13 (#4158)**
cppcheck 2.13.0, the version Ubuntu 24.04 ships, rejects comment lines in a --suppressions-list file with 'Failed to add suppression. No id.'. Keep the four suppressions, move their rationale to cppcheck-suppressions.md beside the file, and add a test that the packaged file holds only bare suppression IDs. Ref #4138.

- **count only glibc libraries' version needs in elf.glibc_requirements (#4161)**
A version need now counts only when its library (the verneed vn_file) is one of glibc's own sonames, listed in the explicit GLIBC_SONAMES set with both the amd64 and arm64 dynamic loaders. On arm64, libgcc_s.so.1 names __register_frame and __deregister_frame GLIBC_2.0, which was wrongly counted as a glibc requirement. Ref vergil-project/vergil-tooling#4139

- **install the host tools on Python 3.15 in consumer-refresh and the install docs (#4163)**
vergil-tooling moved to Python 3.15, but the [publish].consumer-refresh command and the install instructions still pinned --python 3.14. Ref vergil-project/vergil-tooling#4157
