
# Release 2.1.230 (2026-10-07)

## Bug fixes

- **report missing or malformed harvest state as a one-line error (#3120)**
vrg-ci-evidence assemble crashed with a traceback when the pre-publish harvest failed and left no harvest-state.json. read_harvest_state now raises HarvestStateError (a ValueError subclass) for a missing, unreadable, non-JSON, wrong-shape or unknown-schema state file, with a message naming the staging dir and that the pre-publish evidence gate did not complete. resolve_release_pr's unresolvable case now raises ReleasePrUnresolvedError. The CLI catches both and emits a single ERROR / ::error line with exit 1.
