
# Release 2.1.238 (2026-10-12)

## Bug fixes

- **tolerate worktrees removed mid-scan by a concurrent operation (#3190)**
discover_worktrees() is a snapshot; a parallel vrg-finalize-pr can remove a worktree and delete its branch before the status scan reaches it, crashing with a CalledProcessError traceback. On a per-worktree git failure, re-check whether the worktree still exists: if it vanished, drop it with a visible note; otherwise re-raise unchanged. Ref #3187
