
# Release 2.1.245 (2026-10-16)

## Bug fixes

- **tailor the dependency-update gate refusal advice to each blocking PR (#3299)**
Each blocking PR now carries advice for its own case: no fix task linked (merge if green or close deliberately), fix task open (finish the fix; the next release closes the PR), or fix task closed without completing (a human call: close deliberately or reopen the fix). The shared trailer keeps only the --allow-pending-deps advice. Ref #3297.

## Features

- **track git, bash, Xcode Command Line Tools and Claude Code (#3302)**
Add four host dependencies the vrg-host manifest missed.

- git and bash: brew-formula, auto. On a Homebrew-first Mac both resolve to
  Homebrew ahead of the Apple copies, so they are no longer in the
  deliberately-out list.
- xcode-clt: custom, manual (report-only, like macos). Installed from
  pkgutil CLTools_Executables, keeping the first three components
  (26.6.0.0.1781586589 reads as 26.6.0) so it compares with Software
  Update's Version. Latest parses the Command Line Tools items of
  softwareupdate --list (latest_versions); none listed means current; an
  unreadable item or pkgutil answer is a probe error. Missing CLT is ERROR.
- claude-code: brew-cask, auto. The cask does not declare auto_updates
  (Homebrew API, 2026-10-16), reversing the #167 spec's personal-tool
  exclusion because it is the host-side agent for out-of-sandbox work.

Adds recorded and constructed fixtures (labelled in the fixtures README),
tests, and updates the vrg-host reference and getting-started docs.

- **skip current dependencies and report before -> after versions in vrg-host upgrade (#3303)**
vrg-host upgrade now probes and classifies each auto dependency as status does before acting. A current dependency is skipped without running its upgrade command. A behind dependency is upgraded and its installed version is re-probed, so the line reports the real before -> after; an upgrade that leaves the version unchanged is WARN, never 'upgraded'. Dependencies with no latest feed run and report before -> after; missing or probe-error dependencies are ERROR and not attempted. Held lines now show the installed version and the latest held back from. The --all hold exemption from the exit-code roll-up now applies only to pin holds.
