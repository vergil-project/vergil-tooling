
# Release 2.1.268 (2026-10-26)

## Bug fixes

- **refuse a public repo whose owner has no .github up front (#3648)**
resolve_epic_home now probes <owner>/.github for public targets too, reusing the existing not-found check from #3603, and raises EpicHomeError naming the repo to create instead of letting issue or epic creation fail later on GitHub not found. The org-wide require_org_home message now also tells the owner to create <owner>/.github. Ref #3643

Ref #3623.


## Features

- **make the post-prune cache-build floor tunable with VRG_CACHE_BUILD_FREE_GB (#3647)**
The 3 GB floor a cache build needs after an auto-prune is now read from VRG_CACHE_BUILD_FREE_GB (default 3), parsed exactly like VRG_CACHE_PRUNE_FREE_GB through a shared helper: unset or empty means the default, and a value that is not a non-negative number stops the build with an error naming the variable. Both settings are read before every cache build. The floor stays capped at the threshold, and the out-of-space error names whichever setting set it. Documented next to VRG_CACHE_PRUNE_FREE_GB in the container-config reference. Ref #3641
