
# Release 2.1.321 (2026-11-17)

## Bug fixes

- **rebuild a branch cache when its pinned vergil-tooling line has a newer release (#4551)**
* fix(container-cache): rebuild a branch cache when its pinned vergil-tooling line has a newer release

The cache key now names the vergil-tooling release the pin resolves to, read from the vergil package index on every run; the build installs exactly that release and records it in the image. status reports an older cache stale, naming both releases. An unreadable index fails the run, naming the release the cached image holds and the exact pin that reuses it. Ref #4550.

* test(container-cache): cover the index fetch and the self-repo status line

- **write a minimal package.json for a new TypeScript repo (#4554)**
A TypeScript repo created by vrg-github-repo-init had no package.json, so the version cross-check failed on its first CD run. The config-files step now writes one with name, version (equal to VERSION) and private only, and never overwrites an existing one. Ref #4552

- **write Prettier-clean release notes and keep release output out of LINT's Prettier check (#4555)**
* fix(release): write Prettier-clean release notes and keep release output out of LINT's Prettier check

The release note no longer starts with a blank line, and each commit body is indented as its list item's description, so the note is tight Markdown that Prettier leaves as it is. TypeScript LINT's Prettier check now also excludes CHANGELOG.md and releases/*.md, taken from changelog.release_output_paths, beside the managed files. Ref vergil-project/vergil-tooling#4553.

* fix(release): restore the space before the release-notes body template

Ref vergil-project/vergil-tooling#4553.
