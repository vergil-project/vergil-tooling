# Release 2.1.353 (2026-11-27)

## Bug fixes

- **run the apt step and build-command noninteractively (#5308)**
  Export DEBIAN_FRONTEND=noninteractive and TZ=Etc/UTC ahead of the system-packages apt snippet and of every [container].build-command, in the local cache build and in the CI step (vrg-container-build-command --script), so a package with a debconf question such as tzdata cannot hang the build. Ref #5225.

## Refactoring

- **reduce the watch to watching; never turn auto-merge off (#5313)**
  * refactor(finalize): reduce the watch to watching: never turn auto-merge off

  Remove the watch's auto-merge turn-off, the per-head provenance re-check and the gates' re-check, with the failed: provenance and failed: gates outcomes (epic vergil-project/.github#1664, plan Task 10). The one PR path judges every head before it is armed or pushed, so the watch only reports; the merged-PR provenance flag, close-refs, the advisory sync, cleanup and the CD check stay. The gate evaluation the path uses stays in finalize_watch as gates_at_head, and its documentation moves to submit-pr's push mode.

  Ref vergil-project/vergil-tooling#5260

  * test(finalize): drop the watch-in-clone test the watch's new call test covers

  The watch no longer takes a clone, so the test's docstring was stale and its assertion repeats test_watch_keeps_close_refs_cd_and_advisory_stages.
