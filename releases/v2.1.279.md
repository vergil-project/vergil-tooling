## Features

- **add a --plugin-dir override read from ~/.config/vergil/plugin-dirs.toml (#3843)**
* feat(vrg-vm): add a --plugin-dir override read from ~/.config/vergil/plugin-dirs.toml

vrg-vm session reads plugin_dirs from a hand-made host file and adds --plugin-dir for each entry to the claude launch on Lima, after --model. Each directory is checked in the guest before exec, and a missing one fails the launch. A malformed file fails every launch; a cloud session runs the installed plugins and prints a Lima-only notice. Ref #3824.

* fix(vrg-vm): skip plugin-dir guest checks when listing sessions; report an unreadable override file

Listing sessions (no --label, --resume or --fresh) starts no claude, so a plugin directory missing in the guest no longer blocks it; the guard still fails every claude launch. An unreadable, directory-typed or non-UTF-8 plugin-dirs.toml now raises PluginDirsError naming the file instead of escaping as a traceback. Docs and tests updated.
