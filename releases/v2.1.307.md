
# Release 2.1.307 (2026-11-13)

## Bug fixes

- **narrow the catch-all exception in the cwd repo match (#4316)**
_cwd_matches_repo swallowed every exception as no match. It now compares the cwd's git origin with the target repo locally (case-insensitive, no gh call), treats only a non-checkout, a missing origin or a non-GitHub origin as no match, and raises any other git failure as a RuntimeError carrying git's diagnostic, which apply reports as a clean exit-2 error. Ref vergil-project/vergil-tooling#4311.


## Chores

- **uv lock --upgrade**

## Features

- **audit managed files in a fresh clone of develop (#4310)**
vrg-github-repo-config now runs its managed-file checks against a shallow clone of the repo's develop branch in a temporary directory (lib/develop_clone.py), not the caller's cwd. A dirty or unrelated checkout no longer changes the result, --repo audits files from anywhere (the old skipped-with-a-warning path is gone), and a failed clone exits 2 naming the repo. Epic vergil-project/.github#1064, Task 2. Ref #4301.

- **show automation PRs as their own type (#4312)**
A pending-release PR whose head branch is under automation/ shows TYPE automation and is counted in its own summary bucket, apart from development PRs (epic vergil-project/.github#1064, Task 8). Ref #4307

- **add fixers for the hook-guard shim, CLAUDE.md and Claude settings (#4314)**
Each managed file has one drift function that both its audit check and its fixer call, so the check reports drift exactly when the fixer would change the file or raise CannotFix. The shim check now also requires the execute bits, and its fixer writes mode 0755. Ref vergil-project/vergil-tooling#4302.

- **add the mechanized-PR library (#4315)**
lib/mechanized_pr.py opens one auto-merging PR from a fresh develop clone on a per-run automation/<job>/<run-id> branch, after closing and deleting every earlier run's same-repo branch and PR. github.create_pr gains a repo argument passed as --repo.

- **add fixers for .gitignore, dependabot.yml and workflow ref pins (#4318)**
fix_gitignore, fix_dependabot_yml and fix_workflow_refs join FIXERS, each sharing a <name>_drift function with its audit check (epic vergil-project/.github#1064, Task 3b). ManagedFileDrift now carries several audit items and several file writes, so one check can cover several workflow files. A [dependencies].vergil that is not a vX.Y version is drift with no fix, since rewriting the pins to it would break them silently.

- **move the advisory-state sync out of vrg-epic-audit --close into vrg-security-record sync (#4320)**
* feat(security-record): move the advisory-state sync out of vrg-epic-audit --close into vrg-security-record sync

vrg-epic-audit --close no longer runs the security-records pass, so the epic-sweep token needs no Repository security advisories access and can be scoped. The new vrg-security-record sync (with --dry-run) runs the pass under the human's login or the user App. The read-only vrg-epic-audit keeps its preview. Docs and help text updated to match. Ref #4313
