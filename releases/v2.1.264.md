
# Release 2.1.264 (2026-10-24)

## Bug fixes

- **accept intake and planning --epic sentinels in vrg-epic-move and vrg-issue-create (#3516)**
The pre-network cross-org guard in both CLIs exempted only 'adhoc', so 'intake' and 'planning' (accepted by resolve_epic_ref since #2481) were rejected as non-issue-refs. Add a sentinel field to StandingKind and derive epics.EPIC_SENTINELS from STANDING_KINDS; the guards exempt that set and resolve_epic_ref dispatches by each kind's sentinel, so they cannot drift. The --epic help text now lists intake and planning (absorbs #3512). Ref #3514
