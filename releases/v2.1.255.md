
# Release 2.1.255 (2026-10-22)

## Bug fixes

- **run the cache build's warmup with the resolver's UV_PYTHON and UV_PYTHON_PREFERENCE (#3422)**
The cached-image build ran its setup step (vergil-tooling install, build-command, warmup) with uv's defaults plus the repo's own settings, so a repo with python-preference = "only-managed" and no .python-version made uv download a managed interpreter instead of using the image's. ensure_cached_image now takes a required build_env, the same container_env(resolution) the run path passes; the setup step exports it before every fragment (in the shell, so it is not baked into the committed image), and it is folded into the cache key so a change of resolved version or source rebuilds. An empty env adds nothing to the key, so languages without a container env keep their existing caches. vrg-container-run, vrg-container-cache (build and status) and provision_dev_image pass it.
