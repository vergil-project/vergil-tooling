
# Release 2.1.263 (2026-10-23)

## Bug fixes

- **audit every uv.lock group, not just the synced dev environment (#3508)**
The Python audit now exports the whole frozen lock (all groups and extras, minus the project and local path packages) to .vergil/pip-audit-requirements.txt and runs pip-audit against it with --disable-pip --require-hashes, so a vulnerable docs-only pin fails the gate. pip-audit.json stays the evidence report; install, sync check and license check stay on dev. Refs #3498
