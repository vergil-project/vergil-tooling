
# Release 2.1.266 (2026-10-25)

## Bug fixes

- **prune repos without a GitHub origin in App mode (#3625)**
Plain 'git remote' and 'remote get-url' no longer ask for an App token; only remote actions that may reach the remote keep it. A 'git -C <repo>' call takes the token of that repo's own origin org, gets none when the repo has no remote on github.com, and still refuses (NoTargetOrgError) when it has a GitHub remote but no readable origin org. repo_live_branches reads an origin that is not on GitHub from its local tracking refs with a warning instead of over the network. Ref #3624.
