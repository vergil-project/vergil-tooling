
# Release 2.1.303 (2026-11-12)

## Bug fixes

- **retry transient network errors when minting App tokens (#4186)**
The App token path now retries timeouts, resets, refused connections, DNS failures and TLS EOFs with the same bounded backoff lib/retry gives the gh wrappers; a persistent failure still raises AppAuthError once the retries run out.

- **uv lock --upgrade**

## Refactoring

- **drop markdownlint MD013 and lint markdown in one pass (#4103)**
Turn MD013 off in the bundled markdownlint config, delete the now-identical prose config and lint docs/site/, README.md and epics/ in one pass. Remove repo init's description reflow, which only served MD013, and update the lint docs with the reason.
