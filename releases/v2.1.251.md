
# Release 2.1.251 (2026-10-21)

## Bug fixes

- **pass NO_MKDOCS_2_WARNING=1 into the vrg-container-docs container (#3345)**
mkdocs-material 9.7.x prints a MkDocs 2.0 warning banner on every mkdocs run unless NO_MKDOCS_2_WARNING is set. CI and CD already set it (vergil-project/vergil-actions#947); vrg-container-docs now always sets it via build_container_args extra_env for both build and serve, so local builds match CI. Refs #3342.

- **skip cloud memory projection when session only lists (#3351)**
A cloud vrg-vm session with no verb (--label/--resume/--fresh) only lists the workspace's sessions and exits, but it projected and verified memory first, one SSH round-trip per memory file, only to repeat the work on the reconnect. Defer the projection until the invocation names a session or overrides the command. Ref #3346
