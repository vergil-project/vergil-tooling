## Features

- **double the default Lima VM disk to 100GiB (#4792)**
  Per-branch container cache images are 2-3 GB each and several sessions share one VM, so the 50GiB base disk filled up. The base footprint's disk becomes 100GiB; an identity, repo or host override disk still wins. The VM spec reference now states the base size, where the cloud container store lives (the boot disk), and how existing VMs pick up the change. The cloud boot disk default (boot_disk_gib) lives in vergil-vm and is not changed here. Ref #4791
