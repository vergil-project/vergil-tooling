
# Release 2.1.258 (2026-10-23)

## Bug fixes

- **resolve the App-token org from the clone in current_repo(cwd=...) (#3464)**
detect_org() takes an optional cwd, and current_repo(cwd=...) mints its token for the clone's own org inside target_org(), so a fleet sweep started in one org can resolve a private repo cloned from another. An undetectable org raises ValueError and a missing installation raises NoInstallationError; neither falls back to the process-cwd org. Ref #3463
