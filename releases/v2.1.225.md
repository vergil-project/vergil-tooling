
# Release 2.1.225 (2026-10-03)

## Features

- **add the --name instance as a third session-name field (#3067)**
vrg-vm session --name <instance> now passes the instance to the in-VM resolver, which appends it to the session name (<label>:<workspace>:<instance>). The iTerm and Claude Code titles then show which named instance (e.g. local vs cloud) a session runs on. Default (unnamed) instances keep the two-field name.

--resume with an instance renames a pre-instance <label>:<workspace> session to the three-field name via store.rename (history kept) when only the old name exists. --label refuses to create beside such a session and points at --resume.
