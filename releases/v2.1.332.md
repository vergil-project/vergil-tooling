# Release 2.1.332 (2026-11-21)

## Bug fixes

- **resolve vX.Y through its rolling tag (#4863)**
  * fix(tooling-install): resolve vX.Y through its rolling tag

  A line pin vX.Y now reads the tag vX.Y itself, peeled to its commit, in the same single git ls-remote, and takes the one vX.Y.Z tag on that commit instead of the newest patch, so a line demoted with vrg-promote is followed by the dev-container cache, vrg-vm and vrg-tooling-install alike. vrg-tooling-install also accepts vX.Y and installs and reports the exact release it resolves to. Implements Task 2 of epic vergil-project/.github#1440 (spec section 4.6).

## Features

- **run vrg-tooling-install in the Mac consumer refresh (#4836)**
  The consumer refresh replaces its inline shell script, which needed a trap for cleanup, with the installed vrg-tooling-install v<VERSION>, released in 2.1.331. The install guides document the install by hand for a fresh host or a broken installed copy: an unlocked uv tool install of the tag, then vrg-tooling-install to reinstall it locked. Upgrades on any other host run vrg-tooling-install. Refs #4830
- **name the primary's ref in a proxy epic's title (#4842)**
  A proxy is titled 'Epic (proxy): <owner>/<repo>#<N> — <primary subject>', and --proxy-for retitles a reused or reopened proxy whose title differs, so a re-run brings older proxies up to date. Ref vergil-project/vergil-tooling#4840.
