## Documentation

- **describe /usr/bin/git as the xcode-select shim, not a CLT shim (#3310)**
On a Mac with full Xcode, xcode-select selects Xcode.app's toolchain, so /usr/bin/git is not necessarily the Command Line Tools' git. Homebrew still needs the CLT. Ref #3304


## Features

- **refuse to release a package version an earlier release already published (#3311)**
Package builds are not byte-reproducible, so rebuilding a published (name, full version, arch, format) breaks the shared package index for every repo. vrg-release preflight now refuses such a release on a fresh start, before anything is tagged, and vrg-package check-unpublished offers the same check as a CD backstop. Both reuse the index's identity and release-collection logic and fail closed when the published state cannot be read.
