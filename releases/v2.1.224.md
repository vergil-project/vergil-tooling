
# Release 2.1.224 (2026-10-02)

## Bug fixes

- **wait on the base branch's required checks and retry policy blocks (#3061) (#3062)**
Resolve the base branch's required status checks from classic branch protection and repository rulesets, and treat checks as terminal only once every required check is registered and non-pending. CI aggregator jobs register late, so the old registered-only rule let finalize merge into a 'base branch policy prohibits the merge' rejection and abort. That rejection with no failed checks is now treated as not ready: the engine polls and re-attempts within the shared deadline, printing what it awaits, and fails naming the outstanding required checks. A required review aborts immediately. A failed required-check lookup warns and falls back to registered checks only.
