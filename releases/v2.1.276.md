
# Release 2.1.276 (2026-10-27)

## Bug fixes

- **update every plugin install, not one per plugin id (#3764) (#3768)**
claude plugin list --json has one entry per install: the same id at user scope and at project scope for each project. update_plugins keyed the listing by id, so only the last entry was updated and every other install stayed stale. Each entry is now updated at its own scope; a project or local install runs from inside its projectPath (shell-quoted), since claude plugin update has no project flag and takes the project from the working directory. An enabled id with no entry at any scope is still installed at user scope. Failures are collected per entry and name the scope and project: a projectPath missing from the guest fails its cd, and a project entry with no projectPath is a failure without running anything.
