
# Release 2.1.237 (2026-10-10)

## Bug fixes

- **warn about stale checks only when genuinely stale, in plain language (#3183)**
A check gh pr checks reported pending can finish before the statusCheckRollup call; its rollup status is then COMPLETED and nothing is stale. Re-classify it silently and warn only when the rollup status is not COMPLETED but a conclusion is present (#3170). Reword the warning to name the outcome as passed/failed/cancelled/skipped. Ref #3182
