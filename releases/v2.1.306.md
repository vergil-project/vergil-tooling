
# Release 2.1.306 (2026-11-12)

## Bug fixes

- **name every batch issue in the freeze refusal (#4284)**
The report-ready freeze refusal printed by vrg-commit and the vrg-git push path named only state.issue. It now names state.all_issues, so a batch's refusal lists every issue in order; a single-issue record reads as before. Ref vergil-project/vergil-tooling#4280

- **pluralise the worktree summary counts (#4279)**
Use the _count helper for the worktree total and the PR-prepared count, so one worktree reads '1 worktree' and no prepared PRs reads '0 PRs prepared'.
