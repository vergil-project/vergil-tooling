
# Release 2.1.211 (2026-08-29)

## Bug fixes

- **scope stray-check to the repo's own composed fence (#2967)**
gitignore.check() detected stray patterns using the global managed_vocabulary() (base union every language fragment), so a managed pattern belonging to a language other than the repo's own fence (e.g. __pycache__/ in a base-only repo) was flagged as stray with no compliant placement. Scope the stray-check to set(compose(lang)) (base union this repo's declared language) instead: a foreign-language managed pattern is now legitimately repo-local, while a genuine leak of an in-fence pattern is still caught. sync()'s use of managed_vocabulary() is unchanged. Ref #2966.


## Documentation

- **document vrg-gitignore-sync and vrg-fleet-sync in the CLI overview (#2950)**

The reference and consuming-repo guide docs were already migrated to the fenced-only model in #2945; this closes the remaining overview gap. Ref #2918.
