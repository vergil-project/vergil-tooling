
# Release 2.1.232 (2026-10-08)

## Bug fixes

- **scope apt updates in package bootstrap/builder and fail fast on dead mirrors (#3133)**
repo_setup.bootstrap probes for its prerequisites and installs only the missing ones, so a full apt-get update (or a dnf install) happens only when something is actually missing. The update after writing the bootstrap source refreshes that source alone (Dir::Etc::sourcelist, sourceparts=-, List-Cleanup=0). python_builder drops its full update for a scoped refresh of the permanent vergil source the keyring postinst writes, and install_test runs its full update only when the container has no apt indexes yet. Every apt call on these paths carries Acquire::Retries=3 and 20 s http/https timeouts.
