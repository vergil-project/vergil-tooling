## Features

- **require retarget's source and refuse to drop an open tracked issue (#4724)**
  * feat(security-record): require retarget's source and refuse to drop an open tracked issue

  retarget now takes a required source (--from) that the advisory must track, accepting a re-run of an interrupted or finished move, and refuses before any write to stop tracking an open issue other than the source unless --drop names it; each refusal prints the command that would succeed. create makes an advisory's first pairing through a new pair path that refuses an advisory already tracking another issue. vrg-intake-route passes the routed item as the source and keeps every other tracked issue, and its recovery commands carry --from. Ref vergil-project/vergil-tooling#4718.

  * fixup! feat(security-record): require retarget's source and refuse to drop an open tracked issue

- **hold an advisory open while a queue item or a non-completed close is all that ended it (#4725)**

  * style(security-record): format the epic-audit hold tests

  * docs(security-record): state the sync close guard on the issues standards page

- **add the npm updater and its held-back report (#4728)**
- **gate TypeScript dependency licenses on the lockfile (#4729)**
  Add vrg-npm-license-gate, which judges every package in package-lock.json, dev dependencies included, against _TYPESCRIPT_LICENSES_ALLOWLIST as an SPDX expression, honors time-boxed .npm-license-exceptions entries keyed by package and exact license value (at most 365 days), and writes licenses.json. It replaces license-checker --production --summary in the TypeScript AUDIT check. Ref vergil-project/vergil-tooling#4722.
