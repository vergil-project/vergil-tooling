
# Release 2.1.296 (2026-11-10)

## Bug fixes

- **raise the package-index timeout to one hour (#4148)**
Release-dispatched publish-index runs routinely take 20 to 27 minutes, so the 1200s default failed releases whose packages were delivered. Raise the wait_for_index default to 3600s and update the test and releasing guide that state the old value. Ref #4146.


## Features

- **manage images / evidence as a required CI gate behind [ci].images (#4147)**
A repo with [ci].images = true (one whose ci.yml calls its repo-local ci-images.yml as job images) now requires images / evidence in the CI gates ruleset. The gate is in the producible catalog, the ci.yml producibility cross-check recognises ci-images.yml, and it is classified as the evidence-producing images gate, so a release harvests ci-evidence-images. [ci].images must be a boolean. Ref vergil-project/vergil-tooling#4132
