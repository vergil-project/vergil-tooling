
# Release 2.1.248 (2026-10-19)

## Bug fixes

- **probe xdist in the project test env and make the worker count tunable per context (#3323)**
vrg-validate probed pytest-xdist with its own interpreter (the uv tool venv), so consumer repos never got the parallel flags. The probe now runs at test-stage time, after install, against the interpreter beside the pytest on PATH (.venv/bin first). A probe that cannot run, or errors, fails the stage instead of degrading to serial.

The xdist worker count is now tunable: [test].workers ("auto" or a positive int) is the repo default, [test.<context>].workers overrides it for one validation context (ci, local-vm, cloud-vm, physical-host), and VRG_TEST_WORKERS overrides both on one machine. vrg-container-run resolves the context outside the container (GITHUB_ACTIONS, else vrg-whoami --platform) and forwards it as VRG_TEST_CONTEXT. The test stage prints its parallelism decision and where the count came from.
