# Release 2.1.348 (2026-11-25)

## Bug fixes

- **fail a refused workflow push, naming the missing workflows: write grant (#5177)**
  Every in-scope installation now grants the user App workflows: write, so GitHub's workflow-permission refusal means an installation has not accepted it. vrg-git push and vrg-pr-workflow report-ready now fail on it, naming the grant and that the human must accept it on the installation, instead of treating it as an expected hand-off. The stale-branch diagnosis only that path used is removed. Ref #5176.
- **allow the own-merge close GitHub times up to 5 seconds after the merge (#5180)**
  GitHub times the merge and its closed event to the second and sometimes gives the close the next second (vergil-claude-plugin PR #1375), which the same-second rule flagged as a provenance violation. The close now must be the very next timeline event after the one merged event, by the same actor on its own PR, timed 0 to 5 seconds after the merge (MERGE_CLOSE_WINDOW). PR #1375's recorded timeline is added as a fixture beside #87's. Ref #5178.
