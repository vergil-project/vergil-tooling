
# Release 2.1.243 (2026-10-16)

## Features

- **report every pending macOS update level (patch, minor, major) (#3277)**
The macos probe now prints every macOS version softwareupdate offers (new custom probe key latest_versions, one bare version per line). vrg-host status classifies each offer against the installed version by the first differing component and renders each level that is behind, e.g. 'behind (drift): minor 26.7.1, major 27.0.1'. Classification and pins use the leading edge (the highest offer), so severity, exit codes and every other dependency are unchanged. An unreadable macOS offer is a probe error, never dropped.
