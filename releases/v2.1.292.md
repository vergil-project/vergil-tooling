
# Release 2.1.292 (2026-11-09)

## Bug fixes

- **retry HTTP 500 on package-index release reads (#4120)**
The index collector's shared retry never covered a bare HTTP 500, so one intermittent 500 from the release-asset API failed the whole index build (three runs in a row on 2026-11-09). Add a read-only classifier, retry.is_retryable_read, that also accepts HTTP 500, and use it for the collector's gh calls, which are all reads. The shared list is unchanged, because a 500 on a write can mean the write landed and a retry would duplicate it silently.
