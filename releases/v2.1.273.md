
# Release 2.1.273 (2026-10-27)

## Bug fixes

- **retarget finishes an interrupted run when re-run (#3708)**
* fix(security): retarget finishes an interrupted run when re-run

retarget now also unmarks security-labelled issues in the home's org whose advisory line names this GHSA ID (REST listing via security_issues, never search), so a re-run after a failure in any step finishes the job even though the tracking lines were already rewritten. unmark_issue posts its comment first and then drops the line and label in one PATCH, so an interrupted unmark never leaves an issue that the listing can no longer attribute to the advisory. Ref #3702

* fix(security): unmark only the issue line naming this advisory

unmark_issue now takes the GHSA ID and leaves an issue whose body does not name it (another advisory, or none) entirely untouched: no body edit, no label change, no comment. When it does name it, only that one line is removed rather than every advisory line. Ref #3702
