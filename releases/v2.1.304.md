
# Release 2.1.304 (2026-11-12)

## Bug fixes

- **stop saying a submitted PR is frozen to agents in the merge-conflict message (#4253)**
Submitting lifts the freeze, so the conflict message now names pr-watch or the human, and gives single-issue PRs the same rebase and leased push as pr-watch.

- **drop the last frozen-to-agents claim and describe the conflict steps as #4253 makes them (#4259)**
The batch merge-commit refusal now says the agent's pr-watch or the human can fix it, since submitting lifts the freeze. finalize-pr.md now describes rebase and lease-push steps for single-issue and batch PRs, with merge-based steps for release/* branches only.


## Documentation

- **document batched same-repo PRs across the site docs and the worktree convention (#4255)**
Documentation review for epic vergil-project/.github#1019 (Ref #4198): batch PRs in vrg-submit-pr and vrg-finalize-pr, the batch marker subcommands and hard rules in vrg-pr-workflow, the freeze lifting at submit, the epic audit's multi-linkage drift check, merge review in a batch, and the worktree convention's rebase failure mode.

- **name the batch worktree form and the freeze lifting at submit in the consumer template (#4254)**

## Features

- **refuse ubuntu-latest runner labels (#4252)**
Add a runner-labels common check: any scalar value in a .github/workflows/*.yml or *.yaml file that is exactly ubuntu-latest is named by path and line, so GitHub-hosted runners stay pinned to ubuntu-24.04 (epic vergil-project/.github#649, Task 1; issue #4129).
