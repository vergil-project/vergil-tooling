
# Release 2.1.227 (2026-10-06)

## Bug fixes

- **settle confirm-main on the release leaf job, not the first 'release' match (#3103)**
confirm_main waited for the first job whose name contained 'release'. With vergil-actions#905, cd-release adds release / package-matrix (always runs, finishes first) plus package-build/package-sign jobs, so the settle wait could end before release / release concluded and the release would fail falsely (a regression of the #1611 race).

_settled_run_jobs now takes job matchers (predicates on the job name). confirm-main settles on _is_release_job (the leaf-segment matcher that already handles release / release and cd / release, #2001); confirm-develop keeps its substring match via _name_contains('docs').
