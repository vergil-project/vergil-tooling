
# Release 2.1.272 (2026-10-26)

## Bug fixes

- **wait for a newly created standing epic to be listed before returning (#3701)**
ensure_standing_epic is find-or-create over an eventually consistent gh issue list, so two back-to-back calls could each miss the other's new epic and create a duplicate (vergil-project/.github#531/#532). After creating the epic it now polls _find_epic_by_title with retry.compute_delay backoff until the lookup returns exactly the created issue, within the 60 s known-resource budget, and raises StandingEpicNotVisibleError naming the created ref and what was seen if it never does. sleep and clock are injectable for tests. Refs #3695.
